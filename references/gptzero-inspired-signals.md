# GPTZero 理念的合规转化

GPTZero 的公开资料强调词句可预测性、句式和节奏变化、语义一致性、句级解释，以及“检测结果只能结合上下文和人工判断”。SevenWriter 只将这些转化为写作质量信号：

1. **节奏分布**：观察句长与段长是否机械一致；不随机打乱句子。
2. **重复与模板**：定位重复连接词、固定转折和通用套话；命中只产生证据。
3. **语义连贯**：不为追求“意外词汇”牺牲准确性、可读性和专业术语。
4. **句级解释**：每个警告提供位置、证据和修复理由。
5. **场景基线**：邮件、通知、法规和流程文本天然更稳定，不能因“可预测”而误罚。
6. **人工复核**：短文本、编辑文本、混合文本和中文文本不做作者身份结论。

明确不采用：

- 不计算或追逐 GPTZero 私有分数。
- 不把高 perplexity、高 burstiness 当质量目标。
- 不通过生僻词、语病、错别字和无意义长短句变化制造“真人感”。
- 不宣称复现 GPTZero。其官方说明自 2023 年秋已使用深度学习架构，不再直接使用 perplexity 与 burstiness 做检测。
