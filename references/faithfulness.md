# 事实保真与内容契约

## 契约类型

- `LOCK`：字符或语义不可改变。默认包括数字、日期、人名、机构、产品名、URL、引用内容与归属、法律/医学/财务限定语、用户指定关键词。
- `SOFT LOCK`：概念与覆盖范围不可丢，位置和形式可调整。常用于 SEO 关键词、实体、CTA、专业术语。
- `PRESERVE`：结构或格式保持。常用于 Markdown 层级、表格、代码、列表、邮件字段。
- `EDITABLE`：句序、段落、连接、冗余、节奏、语气。
- `UNKNOWN`：材料未证实的内容；不得填补为事实。

## 改写前检查

建立简短清单：

```yaml
intent: rewrite
scene: seo
locks:
  - "2026 年 8 月"
  - "SevenWriter"
soft_locks:
  - "中文写作 Skill"
preserve:
  - "H1-H3"
  - "URLs"
allowed:
  - "sentence_order"
  - "paragraphing"
unknowns:
  - "用户增长数据"
length: "±15%"
```

## 改写后验证

逐项比较源文与候选：

1. 实体、数字、单位、否定词、时间和范围是否一致。
2. 情态是否漂移：可能/预计/计划/建议/必须/已经。
3. 因果、比较对象、引用归属是否变化。
4. 是否新增无法追溯到材料的经历、数据、观点或承诺。
5. 格式和用户指定词是否保留。

任一 LOCK 失败即拒绝候选，不用总分抵消。
