# 样文风格分析

使用 `python scripts/sevenwriter.py style sample1.md sample2.md --output style.json` 提取可观察特征。

## 最低样本要求

- 少于 800 字：低置信度，只能提示倾向。
- 800–3,000 字：中等置信度，可用于句长、段长、标点和人称匹配。
- 超过 3,000 字且来自相同场景：较高置信度，可用于候选比较。

不要跨场景混用邮件、博客和演讲样本。不得复制独特句子、故事或事实；不得声称识别作者身份。

自动特征包括句长、段长、标点、人称、疑问句、连接词和结尾形式。语气、幽默、价值判断与叙事习惯仍由 Agent 结合样文判断。
