# 参考吸收边界

SevenWriter 是独立实现，不复制参考项目的具体提示词、规则表、评分公式、代码或产品协议。

## 只吸收的抽象思想

- 从 `oil-tone` 研究到：静态规则应区分确定错误与上下文警告，脚本不能替代通读。
- 从 `humanize` 研究到：把多个候选置于同一评价框架，从 best-so-far 做定向修复。
- 从 `autoresearch` 研究到：固定评测条件，记录实验，改善则保留、退化则淘汰，同时考虑复杂度成本。

## SevenWriter 的独立设计

- 九层工作流、内容契约类型、场景路由和文档模式。
- 100 分 rubric、硬门槛、failure tag 命名与停止条件。
- 中文场景 profiles、benchmark schema 和标准库 CLI。

## 刻意不采用

- 不绑定特定本地模型、Agent 或安装目录。
- 不要求默认展示全部内部候选和推理过程。
- 不把词表命中当删除命令，不用错别字或随机扰动“骗检测”。
- 不复刻任何厂商 detector，不声称预测其私有分数。
- 不把单一指标设为跨场景真值。
