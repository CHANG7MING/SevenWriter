# Ai好记首页 SEO 修改清单

分析对象：https://aihaoji.com/

说明：这是基于公开可见页面内容的页面级建议，不包含搜索量、排名、转化率、Search Console、服务端渲染结果或竞品关键词数据。上线前仍需查看实际 HTML、结构化数据、canonical、hreflang、性能指标及站长平台数据。

## P0：优先修改

| 位置 | 当前表现 | 建议修改 | 原因 |
|---|---|---|---|
| SEO Title | `Ai好记 - AI音视频转图文` | `Ai好记 - AI音视频转文字、视频总结与图文笔记` | 补充用户更容易理解的核心任务，同时保持品牌与产品定位。 |
| 首页 H1 | 抓取时出现“做会议纪要”，搜索快照还出现“学习外语视频” | 改为稳定的单一 H1：`AI 音视频转文字与总结，把视频、课程和会议整理成图文笔记` | 动态轮换的核心词会使页面主题不稳定；“会议纪要”也不能覆盖实际功能。 |
| 首屏说明 | “专为学习者打造的 AI 知识库……” | 增加上传/粘贴链接、逐字稿、总结、关键画面、思维导图等具体能力 | 目前价值方向正确，但没有在首屏直接说明输入、输出和主要使用场景。 |
| 重复模块 | “从怎么用到解决了什么”“从高效记录到智能学习”在可见 HTML 中重复 | 每个模块只保留一份可索引正文；轮播副本使用正确的前端实现，避免重复进入 DOM 或辅助技术 | 重复内容增加页面噪声，也削弱标题结构。 |
| 用户评价 | 相同评价在可见 HTML 中重复多轮 | 搜索引擎可见正文只保留一组；轮播复制节点不得成为重复正文 | 当前抓取结果中同一批评价多次出现，页面主体被评价文本挤占。 |
| 标题层级 | H2、H3、H4 与轮播副本混杂 | 保持一个 H1；主要能力、场景、流程、耳机、评价、FAQ 使用 H2；具体项目使用 H3 | 让页面结构能够被用户和搜索引擎稳定理解。 |

## P1：内容与搜索意图

### 1. 重排首页信息结构

建议顺序：

1. H1、产品定义和主 CTA
2. 输出结果：图文笔记、逐字稿、总结、思维导图、知识库
3. 使用场景：网课/B站、播客/外语、会议/通话、内容研究
4. 三步使用流程
5. 智能耳机独立入口
6. 经核验的用户评价
7. FAQ
8. 最终 CTA

当前页面在软件、耳机、对比、资本背书和评价之间频繁切换，核心搜索意图不够集中。

### 2. 给关键词建立真正对应的页面

页脚列出了“视频转文字、视频总结、会议总结、B站视频总结、音视频翻译、网课转录、播客转录”等入口。应检查它们是否各自进入内容不同、能解决具体问题的页面。

不要为了关键词批量生成只有标题不同的入口页。每个页面至少应包含：

- 该任务适合什么输入；
- 实际输出是什么；
- 操作步骤；
- 支持范围与限制；
- 示例；
- 常见问题；
- 与相邻功能的区别。

### 3. 首页与博客建立内部链接

首页场景模块可链接到对应教程，例如“如何通过链接生成笔记”。教程再链接回产品功能页和试用入口。锚文本使用真实任务名称，不统一写成“了解更多”。

### 4. 增加有边界的 FAQ

FAQ 应回答支持平台、输出类型、说话人识别、关键帧、翻译、导出、隐私和自动总结核对等真实问题。没有公开依据的格式、时长、准确率和存储期限不要补写。

## P2：技术 SEO 核查项

- 确认 `/` 与 `/zh` 的 canonical 关系，避免相同中文首页形成重复版本。
- 检查语言版本的 `hreflang` 与默认语言跳转，避免搜索引擎抓到不稳定版本。
- 检查首屏 H1 是否由客户端随机切换；核心标题应在服务端 HTML 中稳定输出。
- 检查轮播组件是否复制正文节点，造成抓取文本重复。
- 生成并提交可访问的 XML sitemap；本次公开读取未能确认 sitemap 内容。
- 检查 robots.txt 是否正常返回纯文本和正确状态码；本次公开读取未能确认其内容。
- 为软件产品、组织、文章和面包屑选择符合实际内容的结构化数据；不要给未展示或未核验内容添加标记。
- 图片使用描述内容的 alt；资本机构 Logo、用户头像和产品截图不要都使用泛化名称。
- 检查首页图片、视频与动画对 LCP、CLS 和移动端交互的影响。
- 博客图片路径中出现本地电脑路径式 alt/引用痕迹，应检查发布流程与真实图片 URL。

## 建议保留

- “从怎么用到解决了什么”的思路值得保留，但只保留一份并改成更具体的场景标题。
- 图文转录、关键帧、总结、思维导图与多笔记问答构成了较完整的产品链路。
- 用户评价覆盖教师、医生、学生、内容创作者和管理者，场景多样；应在真实性和授权可核验的前提下精选展示。
- “别让知识只停留在进度条里”与产品问题相关，可以保留作为结尾标题。

## 发布前内容契约

必须锁定或核验：品牌名、公司主体、支持平台、22 种语言、积分规则、设备兼容性、用户身份与原话、资本机构、名人背书、用户规模、隐私与数据处理说明。任何无法核验的项目不得因为 SEO 需要而补成确定事实。
