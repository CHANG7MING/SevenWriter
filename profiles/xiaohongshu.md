# 小红书

- 用户提出创作、爆款、高赞、高收藏或涨粉目标时，读取 `references/high-potential-social-content.md`，默认生成“爆款候选包”；不承诺发布结果。
- 先确定搜索型、推荐型还是交易辅助型目标。标题与封面文字共同表达明确人群、场景和可兑现的信息价值，正文前段立即承接，不用标题党制造无关信息缺口。
- 明确内容身份：真实体验、资料整理、观点分享或品牌内容；不得互相伪装。
- 开头给具体冲突、结果或适用人群，不用夸张悬念骗点击。
- 有材料才写时间、地点、价格、步骤、优缺点和亲历细节。
- 正文至少提供一种可收藏价值：步骤、清单、选择标准、对比依据、避坑条件或可复用示例；不能用堆字和表情代替信息。
- 口语可自然，但不堆“姐妹们、真的绝了、闭眼冲”、感叹号和 Emoji。
- 品牌内容标明边界；优点与限制同样具体。
- 标签、关键词与 CTA 少而相关，不为了热度添加无关词；不诱导虚假点赞、收藏或评论。
- 交付时分别给出标题、封面文字、正文、配图/视频建议、相关话题、置顶评论建议和发布前传播潜力评分。
